# Code of Conduct

## Our pledge

We want Summit Block to be a welcoming project for everyone, regardless of age, background,
ability, gender, experience level, nationality, religion or appearance.

## Expected behaviour

- Be respectful, patient and constructive.
- Assume good faith; critique code and ideas, not people.
- Give credit, welcome newcomers, and answer questions kindly.
- Respect others' time – search existing issues before opening new ones.

## Unacceptable behaviour

- Harassment, insults, discrimination, threats or personal attacks.
- Publishing others' private information.
- Sexualised language or imagery, and unwelcome advances.
- Spam, trolling, or deliberately derailing discussions.

## Enforcement

Maintainers may edit, hide or remove comments, issues and contributions that violate this Code
and may temporarily or permanently ban repeat offenders. Report concerns privately to
**your-email@example.com**; reports are handled confidentially.

## Scope

This Code applies in all project spaces (issues, pull requests, discussions) and when someone
represents the project in public.
